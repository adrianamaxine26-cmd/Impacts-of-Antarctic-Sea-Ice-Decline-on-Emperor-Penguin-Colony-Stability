# Impacts-of-Antarctic-Sea-Ice-Decline-on-Emperor-Penguin-Colony-Stability
Geog 488 - GIS Programming Final Project 
This project examines how the decline of Antarctic sea ice affects emperor penguin colony stability across space and time. Using the Sea Ice Index (NOAA/NSIDC), MAPPPD penguin colony data, and Marginal Ice Zone shapefiles, I analyze how changes in sea ice extent influence breeding success, colony vulnerability, and long‑term population trends. After reprojecting and joining spatial and temporal datasets, I generate time‑series plots and spatial overlays to explore how rapid sea ice loss threatens emperor penguin survival. This project highlights the ecological consequences of climate‑driven sea ice decline and the increasing instability of emperor penguin colonies.
